# Django Celery Reminder System

A small Django project for practicing Celery, Redis, and Celery Beat.

## Features

- Background notification sending with Celery
- Redis as message broker
- Future task scheduling using countdown
- Retry failed tasks
- Periodic reports using Celery Beat
- Database-backed schedules using django-celery-beat
- Celery monitoring with Flower
- Dockerized Django, Redis, worker, beat, and Flower services
